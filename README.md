# Desenvolvimento em JavaScript 🎓

Repositório criado para a disciplina **Desenvolvimento em JavaScript**, com o objetivo de reunir atividades práticas, exemplos de código e projetos desenvolvidos ao longo do semestre.  
Aqui você encontrará implementações que exploram desde conceitos básicos da linguagem até aplicações gráficas com **HTML5 Canvas**.

---

## 📌 Objetivos
- Explorar os principais recursos da linguagem **JavaScript**.  
- Aplicar conceitos de **programação interativa** em páginas web.  
- Desenvolver animações e gráficos utilizando **HTML5 Canvas**.  
- Compreender a importância de estruturas de repetição, funções e eventos na construção de sistemas dinâmicos.  

---

## 📂 Conteúdo
- **Atividades práticas**: exercícios passo a passo para consolidar o aprendizado.  
- **Exemplos de código**: trechos comentados que ilustram boas práticas.  
- **Projetos aplicados**: animações com canvas, geradores interativos e pequenos sistemas web.  

---

## 🚀 Aplicações
Os projetos demonstram como o JavaScript pode transformar páginas estáticas em experiências **dinâmicas e interativas**, aplicáveis em áreas como:
- Jogos simples 🎮  
- Dashboards interativos 📊  
- Ferramentas educacionais 📚
